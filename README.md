# مصابيح الدجى وأئمة الهدى

موقع عن أئمة الدعوة النجدية: سيرة كل إمام، ومؤلفاته، وجهاده، وأثره، مع خريطة تفاعلية للوقائع. كل معلومة فيه موثقة من مصدرها.

## الصفحات

| الملف | المحتوى |
|---|---|
| `index.html` | الصفحة الرئيسية، وفيها الأئمة مرتبون على الأجيال |
| `imams/muhammad-ibn-abdulwahhab.html` | ترجمة الشيخ محمد بن عبد الوهاب |
| `map.html` | خريطة الوقائع: الرحلة والغزوات ودخول البلدان، مع شريط زمني يُشغَّل |
| `sources.html` | المصادر وقواعد العزو |

## البنية

- `assets/css/style.css`: الطراز النجدي (ألوان الطين، والشرفات، والسدو)، والوضع الليلي.
- `assets/js/events.js`: بيانات الخريطة. كل واقعة فيها سنتها، وموضعها، ومصدرها، ورابط صفحتها.
- `assets/js/map.js`: منطق الخريطة (Leaflet).
- `assets/img/`: رسوم SVG (المصباح، والباب النجدي، والأفق).

## إضافة واقعة أو فيديو

أضف عنصراً جديداً إلى `window.EVENTS` في `assets/js/events.js`. ولإضافة فيديو لواقعة، اكتب رابطه في الحقل `video`، فيظهر في نافذة الواقعة تلقائياً.

## إضافة إمام

انسخ `imams/muhammad-ibn-abdulwahhab.html` وعدّل المحتوى، ثم حوّل بطاقته في `index.html` من «قريباً» إلى رابط.

## التشغيل

الموقع ملفات ثابتة لا يحتاج إلى بناء. افتح `index.html` في المتصفح، أو انشره على GitHub Pages.
